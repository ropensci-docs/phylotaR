# Update prinds and tinds

Return tree with updated slots.

## Usage

``` r
pstMnp(tree)
```

## Arguments

- tree:

  `TreeMan` object

## Details

This function is automatically run. Only run, if you are creating yor
own functions to add and remove elements of the `ndlst`.
