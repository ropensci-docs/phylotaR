# Check if tree is correct, fast!

Return T/F if tree is a true `TreeMan` object

## Usage

``` r
fastCheckTreeMan(object)
```

## Arguments

- object:

  `TreeMan` object

## Details

Whenever a tree is first initiated this check is used. For more detailed
checking use `checkNdlst`.
